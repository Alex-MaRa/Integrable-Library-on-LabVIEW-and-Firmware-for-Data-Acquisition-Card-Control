# LabVIEW Library and Firmware for DAQPIC18F4550 Data Acquisition Card Control
This repository provides the firmware and software tools required to control the DAQPIC18F4550 data acquisition card from LabVIEW applications.

## Software
- Firmware for the DAQPIC18F4550 data acquisition card 
- LabVIEW user library for controlling and communicating with the DAQPIC18F4550 data acquisition card.

**Note:** The user library requires a valid LabVIEW license to develop, modify, and use the software. The library is compatible with LabVIEW 2009 and later versions.

## Hardware
- Data acquisition card DAQPIC18F4550
